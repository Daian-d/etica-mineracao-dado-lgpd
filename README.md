# Ética e Responsabilidade na Mineração de Dados
### Uma Análise do Viés Algorítmico e das Exigências de Transparência (LGPD)

## 📝 Sobre o Trabalho
Este repositório contém uma análise técnica e ética sobre como algoritmos de mineração de dados podem reproduzir preconceitos (vieses) e como a **Lei Geral de Proteção de Dados (LGPD)** exige transparência nesses processos.

O trabalho aborda pontos críticos para profissionais de **Engenharia de Software**, como a responsabilidade no desenvolvimento de sistemas automatizados.

## 📄 Conteúdo do PDF (15 páginas)
* **Introdução:** Conceitos de Mineração de Dados.
* **O Problema do Viés:** Como algoritmos podem ser discriminatórios.
* **LGPD e Transparência:** Regulações sobre decisões automatizadas.
* **Conclusão:** Boas práticas para engenheiros de software.
